# Portofolio Cintya Nurdaiman Ode

Website portofolio statis yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Menjalankan

Buka `index.html` di browser. Tidak diperlukan instalasi atau proses build.

## Sebelum dipublikasikan

- Periksa kembali riwayat pendidikan dan daftar keahlian.
- Ganti ilustrasi/contoh proyek dengan proyek nyata, dokumentasi, gambar, dan tautannya.
- Isi bagian pengalaman, prestasi, serta sertifikat jika tersedia.
- Tambahkan alamat email, tautan GitHub/LinkedIn, foto profil, dan CV bila ingin dibagikan.
- Uji tampilan di perangkat desktop dan seluler.

Proyek pada halaman saat ini ditandai sebagai contoh akademik/praktikum yang disarankan dalam `portofolio.md`, bukan pernyataan bahwa proyek tersebut telah dikerjakan.
